关键技术实现
═══════════════════════════════════════════════════════════════

1. 生命继承机制
   ┌─────────────┐
   │ 战斗前加载   │ → unit.Stats.CurrentHP = instanceData.CurrentHP
   └─────────────┘
   ┌─────────────┐
   │ 战斗中变化   │ → unit.TakeDamage(damage)
   └─────────────┘
   ┌─────────────┐
   │ 战斗后保存   │ → instanceData.CurrentHP = unit.Stats.CurrentHP
   └─────────────┘

2. 职业系统（策略模式）
   BaseSummonerClass (抽象基类)
        ├── BerserkerClass  (狂战)
        ├── WarlockClass    (术士)
        ├── ChaosClass      (混沌)
        └── DruidClass      (德鲁伊)

3. 敌人AI（有限状态机）
   Patrol → Alert → Chase → Combat
      ↑                        │
      └────────────────────────┘
              Rest

4. 事件系统（观察者模式）
   EventManager
        ├── AddListener<T>()
        ├── RemoveListener<T>()
        └── TriggerEvent<T>()

5. 网络同步（确定性战斗）
   Server: SyncRNGSeed(seed)
        ↓
   Client: Random.InitState(seed)
        ↓
   确保双方战斗结果一致
