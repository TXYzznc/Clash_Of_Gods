## 💎 技术特色

### 1. 生命继承机制
```csharp
// 战斗前加载
unit.Stats.CurrentHP = instanceData.CurrentHP;

// 战斗后保存
instanceData.CurrentHP = unit.Stats.CurrentHP;
```
**特点**: 实现Roguelite的高风险高回报

### 2. 职业系统（策略模式）
```csharp
BaseSummonerClass
├── BerserkerClass  // 狂战
├── WarlockClass    // 术士
├── ChaosClass      // 混沌
└── DruidClass      // 德鲁伊
```
**特点**: 易于扩展新职业

### 3. 敌人AI（五状态FSM）
```
Patrol → Alert → Chase → Combat
   ↑                        ↓
   └────────── Rest ────────┘
```
**特点**: 行为可预测，易于调试

### 4. 网络同步（确定性战斗）
```csharp
// 服务器生成种子
SyncRNGSeed(seed);

// 客户端使用相同种子
Random.InitState(seed);
```
**特点**: 减少带宽，保证一致性
