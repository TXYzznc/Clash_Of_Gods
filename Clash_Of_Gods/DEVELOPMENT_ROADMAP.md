# 《诸神对决》开发路线图

## 项目概述

基于策划案分析，本项目是一款融合 **卡牌 + 自走棋 + Roguelite + 搜打撤** 的策略游戏。

---

### ✅ 已完成的基础架构

| 模块 | 状态 | 说明 |
|------|------|------|

| 单位系统 | ✅ 基础 | UnitEntity, UnitStats, UnitAIController |

## 立即开始：第一个任务

### 推荐从「召唤物系统」开始

**原因**：
1. 召唤物是游戏的核心单位，所有战斗都围绕召唤物展开
2. 已有 `UnitEntity` 基础，可以在此基础上扩展
3. 完成后可以立即进行战斗测试
4. 不依赖其他未完成的系统

## 技术要点

### 1. 数据驱动设计

```csharp
// 使用 ScriptableObject 配置数据
[CreateAssetMenu(fileName = "NewUnit", menuName = "ClashOfGods/Unit Config")]
public class UnitConfig : ScriptableObject
{
    public int UnitID;
    public string UnitName;
    public UnitType Type;
    public int PopulationCost;  // 人口消耗
    public EvolutionConfig[] EvolutionBranches;  // 进化分支
    public SkillConfig[] Skills;  // 技能列表
    // ...
}
```

### 2. 组件化设计

```csharp
// 召唤物由多个组件组成
GameObject: SummonedUnit
├─ UnitEntity (核心属性)
├─ UnitSkillSystem (技能系统)
├─ UnitEvolution (进化系统)
├─ UnitEquipment (装备系统)
├─ UnitAIController (AI控制)
└─ UnitNetworkSync (网络同步，可选)
```

### 3. 事件驱动通信

```csharp
// 使用事件系统解耦
EventManager.Instance.TriggerEvent(new UnitEvolutionEvent
{
    Unit = this,
    FromForm = currentForm,
    ToForm = newForm
});
```
